# Boston Logan Airport Flight Board

Commercial departures, arrivals, and local aircraft routing for Boston Logan (KBOS), with a route map.

The public site is [pdirubbo.github.io/boston-logan-flight-board](https://pdirubbo.github.io/boston-logan-flight-board/). GitHub rebuilds it from the live schedule every 10 minutes.

The board also refreshes every 10 minutes while it is open, and again on load when the last pull is older than 10 minutes.
